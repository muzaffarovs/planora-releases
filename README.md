# Planora releases

Built Windows versions of Planora (a daily and weekly planner with Telegram reminders and a
budget). This repository holds only the packaged app; the source code is private.

Installed copies of Planora check here and update themselves. Each release's notes include the
zip's SHA-256, which the app verifies before installing.

Website: https://muzaffarovs.github.io/planora-releases/ (served from this repository).
Latest installer: https://github.com/muzaffarovs/planora-releases/releases/latest/download/PlanoraSetup.exe
